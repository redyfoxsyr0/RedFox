Security System
RedFox Anti‑Cheat Engine

The RedFox Anti‑Cheat Engine is a physics‑driven detection system designed to identify movement spoofing, noclip, teleport abuse, fly hacks, walk‑fling, air jumps, and workspace tampering.

Every player is tracked with a dedicated PlayerState object, storing velocity history, fall data, teleport samples, noclip samples, safe positions, and strike counts.

Core Detection Systems

  • Fling Detection: Detects abnormal Y‑velocity spikes, angular velocity abuse, and walk‑fling patterns.
  • Teleport Detection: Step‑TP thresholds scale with ping and delta‑time to avoid false positives.
  • Noclip Detection: Multi‑raycast + blockcast + OBB inside‑wall detection.
  • Fly Detection: Tracks planar velocity, downward velocity, and physics state over time.
  • Air Jump Detection: Prevents mid‑air jump spoofing using vertical velocity and timing.
  • Dev Console Detection: Identifies executor‑generated console noise, including unauthorized errors, injected prints, malformed stack traces, and non‑game debug output.
  • Chat Command Detection: Monitors chat for non‑whitelisted command patterns (e.g., : ; ! fly, noclip, speed) and flags users without the required group rank.
  • Masked Remote Detection: Enforces randomized remote identifiers, rejecting all calls made to human‑readable remote names and flagging spoofed remote invocations.
  • Workspace Integrity: Detects tampering with protected instances, size changes, transparency edits, and movement.
