Detection Vectors & Logic
Fling & Fly Heuristics ACTIVE

Monitors the HumanoidRootPart for non-associative physics changes.

  • Centrifugal Force: Detects AngularVelocity spikes exceeding 100 rad/s to prevent walk-flings.
  • Y-Axis Variance: Identifies sustained hover states where Gravity is nullified without a flight-seat.
  • State Spoofing: Flags "Freefall" states that last longer than the maximum possible terminal velocity height.
Spatial Integrity (TP/Noclip) ACTIVE

Validates player positioning through server-side OBB (Oriented Bounding Box) checks.

  • Magnitude Validation: Compares (Pos1 - Pos2).Magnitude against WalkSpeed * DeltaTime with a +15% latency buffer.
  • Raycast Interception: Fires server-side rays between previous and current frames to detect passage through "CanCollide" geometry.
  • Void Tracking: Auto-resets position if a player enters un-rendered coordinates below the map floor.
Workspace Integrity MONITORING

Detects local environment tampering and unauthorized modification of static assets.

  • Instance Protection: Flags the deletion of critical map boundaries or "Kill-Bricks" via client-side ChildRemoved listeners.
  • Property Auditing: Detects locally modified Transparency or Size on walls (X-Ray/Hitbox Expander detection).
  • Desync Analysis: Identifies when a client's workspace.CurrentCamera position deviates from expected physics constraints.
Network Obfuscation ACTIVE

Protects the Client-Server Bridge via dynamic identity verification.

  • Dynamic Remotes: RemoteEvents are renamed every session; static calls to "AdminRemote" result in an instant ban.
  • Argument Scrubbing: Validates that every FireServer call matches expected Type-Arrays.
  • Rate Limiting: Enforces a per-player "Packet Budget" to prevent Remote-Spam and server-crashing attempts.
