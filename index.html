Security Manual
Detection Vectors & Logic
PHYSICS & FLING HEURISTICS ACTIVE
  • Centrifugal Force: Monitors AssemblyAngularVelocity. Flags spikes exceeding 150 rad/s to stop "Spin-Flings".
  • Walk-Fling Logic: Detects high planar speeds (>85) combined with angular velocity (>35) while grounded.
  • Hover Tracking: Flags players maintaining near-zero Y-velocity while in a "Physics" or "Freefall" state for >1.2s.
SPATIAL INTEGRITY (TP/NOCLIP) ACTIVE
  • Dynamic Thresholds: TP limits scale using BaseDist + (Ping * 0.06) + (DeltaTime * 180) to prevent lag-back.
  • Raycast Interception: Fires triple-height rays (0.6 to 4.2 studs) to detect passage through solid CanCollide geometry.
  • OBB Analysis: Uses GetPartBoundsInBox to detect if a player's hitbox is deep inside a wall for >0.15s.
WORKSPACE & ASSET INTEGRITY MONITORING
  • Property Auditing: Flags client-side changes to Transparency (X-Ray) or Size (Hitbox Expanders).
  • Ancestry Protection: Uses ChildRemoved listeners to detect deletion of map boundaries or kill-bricks.
  • State Restoration: Optional server-side enforcement that auto-reverts unauthorized CFrame or Material edits.
NETWORK OBFUSCATION ACTIVE
  • Masked Remotes: Rejects calls to human-readable names; identifiers are randomized per-session to prevent script hardcoding.
  • Rate Limiting: Tracks RemoteWin count/window; flags accounts exceeding packet budgets to stop remote spam.
  • Argument Scrubbing: Validates incoming FireServer data against expected type-arrays to prevent injection.
ENVIRONMENT & SOCIAL AUDIT ACTIVE
  • Console Noise: Identifies executor-generated error signatures and injected print/warn noise via LogService.
  • Chat Command Hook: Scans for restricted prefixes (: ; ! /) and flags unauthorized "Fly" or "Speed" strings.
  • Air Jump/Inf Jump: Detects Jumping states while not grounded for >0.35s to stop mid-air leap spoofing.
HARDENING & RECOVERY ACTIVE
  • Smooth Recovery: Upon violation, the server tweens the player to their lastSafeCF and resets physics.
  • Collision Hardening: Forces all player parts into a specific CollisionGroup to prevent client-side physics exploit clipping.
  • Void Handling: Automatically triggers a safe recovery if the player's Y-coordinate drops below -60.
